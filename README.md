
# HR Analytics Dashboard

## Project Overview
An interactive HR Analytics Dashboard designed to help HR professionals monitor workforce performance and make data-driven decisions.

## Project Objectives
- Monitor employee headcount.
- Analyse employee attrition.
- Track recruitment performance.
- Monitor attendance and absenteeism.
- Analyse payroll expenditure.
- Track workforce demographics.

## Dashboard Modules
1. Workforce Overview
2. Employee Attrition Analytics
3. Recruitment Analytics
4. Attendance Analytics
5. Payroll Analytics
6. Department-wise Analysis
7. Diversity Analytics
8. Employee Performance Analytics

## Technology Stack
- HTML
- CSS
- JavaScript
- Chart.js
- GitHub
- Vercel

## Dataset
This project will use fictional/synthetic employee records for demonstration purposes.
